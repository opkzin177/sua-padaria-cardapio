# Sua Padaria - Cardápio Lanchonete

Site online do cardápio da Lanchonete da Sua Padaria.

## Recursos

- Visualização por categorias
- Busca por nome ou código do produto
- Design responsivo (mobile-friendly)
- Tema escuro com detalhes dourados

## Tecnologias

- HTML, CSS e JavaScript puro
- Hospedado na Netlify

## Como atualizar

Edite o arquivo `index.html` e faça o deploy novamente.
